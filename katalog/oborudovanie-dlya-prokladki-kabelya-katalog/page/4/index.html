    Оборудование для прокладки кабеля

    Техника для укладки силового и связного кабеля в грунт и в кабельные сооружения: вибрационные кабелеукладчики, траншейные ролики, оснастка для колодцев, вентиляторы, ролики для лотков, оснастка для муфт и комплекты для воздушных линий. Раздел собран по месту работы: траншея, колодец, лоток, опора.
